PRIVACIDAD

Cómo tratamos los documentos en la versión de prueba

Esta página describe el funcionamiento actual del prototipo de DocuListo. La información se actualizará antes de abrir el servicio a uso general.

¿Se guarda mi documento?

DocuListo recibe el archivo para poder analizarlo. En el backend actual se procesa en memoria y no se guarda en disco ni se mantiene una copia en una base de datos.

¿Se envía a un servicio externo?

Sí. El análisis utiliza un proveedor externo de IA. DocuListo envía el contenido necesario para generar el resultado y la configuración del backend solicita que la interacción no se almacene como una conversación.

¿Qué puedo hacer durante la prueba?

No subas DNI, certificados, historiales médicos, datos bancarios, contraseñas, documentos con firmas ni otra información especialmente sensible. Esta versión está pensada para validar el funcionamiento con documentos de prueba o con información que puedas compartir con seguridad.
