Tu privacidad y tus documentos

Esta política explica qué datos trata actualmente DocuListo, para qué los necesita y qué proveedores intervienen.

Responsable del tratamiento

Alex Muñoz Castellano, titular de DocuListo. Contacto: hola@doculisto.es. El domicilio o establecimiento legal se incorporará al aviso legal cuando se complete ese dato.

Datos que tratamos

Podemos tratar el archivo que subas para analizarlo, su nombre y metadatos básicos, datos técnicos necesarios para prestar y proteger el servicio y, cuando exista consentimiento, datos de analítica web.

Finalidades y bases jurídicas

Utilizamos el documento para realizar el análisis solicitado. La base jurídica dependerá del tratamiento concreto y podrá incluir la ejecución de la solicitud del servicio y el consentimiento cuando corresponda. La analítica no esencial se carga únicamente después de una acción afirmativa.

Procesamiento del documento

El backend actual procesa el archivo en memoria y no mantiene deliberadamente una copia en una base de datos propia. El contenido sí se transmite a proveedores técnicos necesarios para generar el análisis.

Google Gemini

DocuListo utiliza la API de Gemini de Google. La petición actual usa store=false para evitar crear una interacción persistente. Las condiciones de Google distinguen el almacenamiento de interacciones de los registros limitados que pueden existir por seguridad, prevención de abusos u obligaciones legales.

Google indica que, para el uso de la API desde el Espacio Económico Europeo, las condiciones de uso de datos de los Servicios Pagados se aplican también a la cuota no pagada. En esos Servicios Google no utiliza los prompts, archivos y respuestas para mejorar sus productos, aunque puede conservarlos durante un periodo limitado para seguridad, prevención de usos prohibidos y obligaciones legales.

No envíes documentos que no estés autorizado a compartir ni información especialmente sensible si no es necesaria.

Condiciones de la API de Gemini · Información sobre retención de datos.

Render

El backend se ejecuta en Render. En la configuración actual no guardamos los documentos en disco. La documentación de Render indica que el periodo de retención de logs depende del plan y que en el plan Hobby es de 7 días. Los logs de aplicación de DocuListo no están diseñados para incluir el contenido del documento.

Google Analytics

DocuListo utiliza Google Analytics para estadísticas de uso. En la configuración actual se carga solamente después de aceptar la medición. Puedes rechazarla y seguir utilizando la web.

Google AdSense

Cuando se active Google AdSense, se incorporará la configuración de consentimiento necesaria para publicidad. Para usuarios del Espacio Económico Europeo, Reino Unido y Suiza, Google exige una CMP certificada e integrada con el TCF cuando se sirvan anuncios personalizados.

Conservación

Los datos se conservarán durante el tiempo necesario para la finalidad correspondiente y durante los plazos que puedan resultar exigibles por ley. Los proveedores externos pueden aplicar sus propios periodos de conservación.

Derechos

Puedes solicitar acceso, rectificación, supresión, limitación u oposición cuando proceda escribiendo a hola@doculisto.es. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.

Última actualización: 21 de septiembre de 2026. Esta política deberá revisarse cuando cambien los proveedores, la monetización o el modo de tratamiento de documentos.
